# OptimusTech — 7 Days of Code

Landing page de carreiras de uma empresa fictícia, desenvolvida com HTML e CSS no desafio 7 Days of Code.

[Ver projeto publicado](https://site-work.vercel.app)

## Conteúdo da página

- Apresentação institucional e indicadores.
- Lista de vagas por área.
- Depoimento de uma colaboradora fictícia.
- Campo visual de inscrição para receber oportunidades.

## Tecnologias e aprendizados

HTML5 e CSS3, com prática de estruturação de seções, tipografia, espaçamento e composição de layout.

## Como executar

Clone ou baixe o repositório e sirva a pasta em um servidor estático, como Live Server. Também é possível abrir `index.html` diretamente; o servidor é recomendado porque a imagem principal utiliza um caminho absoluto iniciado por `/assets/`.

Não há instalação de dependências nem etapa de build.

## Estrutura

- `index.html`: conteúdo.
- `style.css` e `reset.css`: estilos disponíveis.
- `assets/`: imagens e ícones.

## Escopo

O projeto é uma demonstração de interface. Os números, vagas e depoimentos são conteúdo fictício; os botões e o campo de e-mail não estão integrados a um sistema de recrutamento.

A página ainda referencia `css/style.css`, arquivo ausente na estrutura atual, além do `style.css` existente.

Exercício do 7 Days of Code, associado à Alura. Marcas e recursos visuais mantêm seus respectivos créditos.
